realtwin.rt_sumo.xodr_sumo.xodr_from_net_xml

realtwin.rt_sumo.xodr_sumo.xodr_from_net_xml(net_file: str | Path | None = None, xodr_file: str | Path | None = None, *, net: sumolib.net.Net | None = None, netconvert_binary: str | Path | None = None, netconvert_options: Mapping[str, Any] | None = None, opendrive_map_kwargs: Mapping[str, Any] | None = None) → OpenDriveMap[source]

Convert a .net.xml file or sumolib.net.Net object to pyopendrive.OpenDriveMap.

sumolib.net.Net does not provide a native writer. If net_file is not passed, this function first reuses the source file attached by xodr_to_net_xml(). If no source path is available, it writes a minimal SUMO net XML representation from the in-memory object and passes that to netconvert.

The source SUMO file is never edited. Road and junction identities are restored from netconvert’s source metadata, independently of XML order. Source lane IDs and signal programs are retained in OpenDrive userData for an explicit conversion back into a separate SUMO output.

Parameters:

  • net_file – Optional SUMO .net.xml path to use as the source for netconvert.

  • xodr_file – Optional output OpenDRIVE .xodr path. When omitted, a temporary file is created and retained through an attribute on the returned map.

  • net – Optional sumolib.net.Net object to convert. if net_file is not provided, this is required to resolve the source net.

  • netconvert_binary – Optional path or executable name for SUMO netconvert. When omitted, netconvert is resolved from PATH.

  • netconvert_options – Extra command-line options for netconvert as {"option": value}.

  • opendrive_map_kwargs – Extra keyword arguments passed to pyopendrive.OpenDriveMap.

Returns:

A pyopendrive.OpenDriveMap loaded from the generated OpenDRIVE file.

Raises:

  • RuntimeError – If netconvert is unavailable or exits with an error.

  • ValueError – If the output would overwrite the input or required source edge mappings are missing.
