realtwin.rt_sumo.xodr_sumo.xodr_to_net_xml

realtwin.rt_sumo.xodr_sumo.xodr_to_net_xml(xodr_file: str | Path, net_file: str | Path | None = None, *, netconvert_binary: str | Path | None = None, netconvert_options: Mapping[str, Any] | None = None, read_options: Mapping[str, Any] | None = None, import_all_lanes: bool = True, with_internal: bool = True) → sumolib.net.Net[source]

Convert an OpenDRIVE .xodr file to a sumolib.net.Net object.

Files exported by xodr_from_net_xml() carry metadata for restoring source SUMO junction, edge and lane IDs, TLS programs and controlled lane connections. OpenDrive uses local integer lane IDs; SUMO lane names are retained separately in userData. For other OpenDrive files, native generated IDs are retained and their OpenDrive origins are recorded as parameters. Roads split by netconvert retain generated segment IDs.

Parameters:

  • xodr_file – Source OpenDRIVE file.

  • net_file – output SUMO .net.xml path.

  • netconvert_binary – Optional path or executable name for SUMO netconvert. When omitted, netconvert is resolved from PATH.

  • netconvert_options – Extra command-line options for netconvert as {"option": value}.

  • read_options – Extra keyword arguments passed to sumolib.net.readNet.

  • import_all_lanes – Whether to pass --opendrive.import-all-lanes.

  • with_internal – Value passed as withInternal to sumolib.net.readNet unless overridden by read_options.

Returns:

The converted network object.

The generated SUMO net XML file is retained and its path is attached to the returned object as an attribute.

Return type:

sumolib.net.Net

Raises:

  • RuntimeError – If sumolib or netconvert is unavailable, or if netconvert exits with an error.

  • ValueError – If the output would overwrite the input, original-name metadata is disabled, or controlled lane connections cannot be restored after conversion.
