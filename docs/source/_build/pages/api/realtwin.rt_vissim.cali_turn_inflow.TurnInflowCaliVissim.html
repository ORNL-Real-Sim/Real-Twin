realtwin.rt_vissim.cali_turn_inflow.TurnInflowCaliVissim

Calibration supports genetic algorithm (GA), simulated annealing (SA), tabu search (TS), and Bayesian optimization (BO).

class realtwin.rt_vissim.cali_turn_inflow.TurnInflowCaliVissim(*, input_config: dict, evaluator: Evaluator, verbose: bool = True)[source]

Optimize demand with a live evaluator and effective per-stage settings.

Parameters:

  • input_config – Configuration containing VISSIM.turn_inflow, including scenario_config, turn_inflow and algorithm configuration blocks.

  • evaluator – Loaded Vissim session’s normalized demand objective.

  • verbose – Print BO progress. Evaluation history is always recorded.
