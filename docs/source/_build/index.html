Welcome to realtwin documentation!

Real-Twin provides scenario generation and calibration through RealTwinSUMO, RealTwinVISSIM, and RealTwinAimsun. The current workflows support traffic demand with optional external signal control and independent turn/inflow and behavior calibration using genetic algorithm (GA), simulated annealing (SA), tabu search (TS), or Bayesian optimization (BO).

Important

The current Real-Twin package supports Windows only.

Start with Installation, configure your data using Preparation, and follow Scenario Generation. The SUMO vehicle-type workflow is described in Autonomous Vehicle Simulation.
